FUNCIONES
1. Crear cuenta: guarda una cuenta de demostración en el navegador.
2. Iniciar sesión: permite usar la cuenta creada.
3. ¿Olvidaste tu contraseña?: verifica el correo registrado y simula el envío de un enlace.

IMPORTANTE
Es una práctica frontend. Para un proyecto real, el registro, inicio de sesión y recuperación deben conectarse a un backend y una base de datos. Las contraseñas nunca deben guardarse directamente en localStorage.
